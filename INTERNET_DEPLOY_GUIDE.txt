RUMMY JKRN - INTERNET MULTIPLAYER DEPLOYMENT
===============================================

This package is ready for a public Node.js web host such as Render.

IMPORTANT:
- Do not double-click the HTML for internet multiplayer.
- The server must host the HTML.
- The current game rooms are stored in server memory. If the server restarts,
  active rooms are lost. This is acceptable for the first multiplayer test.

RENDER STEPS:
1. Create a GitHub repository and upload these files:
   RUMMY_JKRN_REAL_PLAYERS_V4.html
   server.js
   package.json
   render.yaml
   .gitignore
2. In Render, create a Web Service from that GitHub repository.
3. Render can use the render.yaml settings, or set:
   Build Command: npm install
   Start Command: npm start
4. After deployment, Render gives a public HTTPS address such as:
   https://rummy-jkrn-real-players.onrender.com
5. Open that address on Mobile 1 and create a room.
6. Send the same public address + Room ID to Mobile 2/3/4/5/6.
7. They enter their names and Join Room.

NO PORT CHANGE IS REQUIRED:
server.js already uses process.env.PORT for hosting.

NEXT PRODUCTION UPGRADE:
For a serious public game, move rooms/game state to Redis or a database,
add authentication/rate limits, and persist match history.
